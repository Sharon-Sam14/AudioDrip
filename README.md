# AudioDrip 🎵

AudioDrip is a premium, highly animated music streaming and offline caching web application. It streams audio directly, downloads/caches songs locally for zero-buffer offline playback, and features synced lyrics auto-scrolling alongside a real-time audio canvas frequency visualizer.

---

## 🛠️ Technology Stack

- **Frontend**: React 19, Vite, TypeScript, Tailwind CSS v4, Framer Motion, Lucide React
- **Backend**: Python 3.13, FastAPI (lifespan manager, stream caching, YouTube stream proxying)
- **Database**: PostgreSQL (song catalog, behavior transitions, liked songs, playlists, users)
- **Downloader**: yt-dlp (background threads)

---

## 🚀 Quick Start (Windows)

**Prerequisite**: Install [PostgreSQL](https://www.postgresql.org/download/) and [Python 3.11+](https://python.org).

### Option A — One-Click Launch
1. Open `Server/.env` and set your PostgreSQL password.
2. Double-click **`start.bat`** in the root directory.
3. Navigate to **http://localhost:8000** in your browser.

### Option B — Manual Setup

#### Step 1: Configure PostgreSQL
Edit `Server/.env`:
```env
DB_USER=postgres
DB_PASSWORD=YOUR_POSTGRESQL_PASSWORD
DB_HOST=localhost
DB_PORT=5432
DB_NAME=audiodrip
```

#### Step 2: Install Python Dependencies
```bash
cd Server
python -m pip install -r requirements.txt
```

#### Step 3: Initialize the Database
```bash
python init_db.py
```
This creates all tables and imports any existing local JSON data.

#### Step 4: Start the Server
```bash
python app.py
```
The server starts at **http://localhost:8000**.

## ✨ Features

| Feature | Description |
|---|---|
| 🎵 **Stream** | Real-time audio stream via yt-dlp + YouTube proxy |
| 📥 **Offline Cache** | Downloads songs to local disk for zero-buffer playback |
| 🎤 **Synced Lyrics** | Auto-scrolling time-synced lyrics via LRCLIB |
| 📊 **Visualizer** | Canvas-based audio frequency visualizer (Bars / Orbit / Tape) |
| 🤖 **AI Playlists** | Groq LLaMA-powered AI playlist generation from a text prompt |
| ❤️ **Library** | Like songs, create playlists, manage offline cache |
| 🔍 **Spotlight Search** | Cmd/Ctrl+K command-palette search with keyboard navigation |
| 🌙 **Themes** | Obsidian Studio (dark) and Daylight Session (light) |
| 🔐 **Auth** | Email + password user accounts with password reset |

## 🤖 Optional: AI Playlists (Groq)

To enable AI playlist generation, add your free Groq API key to `Server/.env`:
```env
GROQ_API_KEY=gsk_your_key_here
```
Get a free key at [console.groq.com](https://console.groq.com).

Without this key, a local keyword-matching fallback is used automatically.

## 👨‍💻 Development Mode

To run the React frontend with hot-reload during development:

```bash
cd Frontend
npm install
npm run dev
```
Navigate to **http://localhost:5173**. API calls proxy automatically to the backend on port 8000.

To compile changes into the server's static directory:
```bash
npm run build
```

## 🗄️ Database Tables

| Table | Purpose |
|---|---|
| `songs` | Song catalog with metadata + embeddings |
| `playback_transitions` | Behavior-based skip pattern tracking |
| `liked_songs` | Per-user liked songs |
| `playlists` + `playlist_songs` | User playlists |
| `users` | Email/password user accounts |
| `user_interactions` | Interaction scoring for recommendations |
| `system_settings` | Server state (e.g. last decay timestamp) |
